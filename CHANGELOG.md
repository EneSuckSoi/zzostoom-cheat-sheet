# Changelog

## 1.4.0 - languages
- The menu is now available in 10 languages: English, German, French, Spanish, Portuguese (Brazil),
  Russian, Japanese, Korean, Simplified Chinese and Turkish. English is the default; pick one in
  Settings > Language (it is remembered).
- Item names, descriptions, weapon types, attributes and affinities use the game's own official
  translations, so they match your inventory. "Show item names in English" switches them back,
  and searching by the English name works in every language.
- Chinese, Japanese and Korean text uses the Windows fonts (Microsoft YaHei UI, Yu Gothic UI,
  Malgun Gothic).

## 1.3.0 - first public release
- Reveal the whole map and unlock all Sites of Grace (base game and DLC) now work: the event
  flags are written directly and verified by reading them back.
- Torrent is detected correctly while riding (Torrent speed and jump boost on Torrent).
- Fly mode: vertical speed eases in, so short presses move slowly even on controllers with
  digital triggers.
- Menu key can be the key under Esc (works on every keyboard layout).

## 1.2.0
- Fixed a short stutter every second (memory access no longer uses system calls).
- Player / Torrent speed and jump boost rewritten so they also work with Seamless Coop.
- Fly mode: A (jump) rises instead of leaving the character stuck in a jump; analog triggers.

## 1.1.0
- Fixed the frame rate dropping to ~30 FPS when movement cheats were on.
- Single fly mode (noclip) with RT/LT, turns off on death and loading screens.
- Saved positions restore correctly (no more falling under the ground).
- World tab (map / Sites of Grace), English UI, one-column cheat list for controller navigation.
- Removed auto parry.

## 1.0.0
- In-game menu: items, cheats, movement, character, saves, settings.
- Controller support (L3 + R3) and shortcuts.
